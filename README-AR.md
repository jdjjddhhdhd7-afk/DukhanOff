# دخان أوف 🚭 — DukhanOff

هذا مشروع Android جاهز للبناء أونلاين بواسطة GitHub Actions.

## المتطلبات
- حساب GitHub مجاني.
- لا تحتاج Android Studio.
- لا تحتاج كمبيوتر؛ يمكن تنفيذ الخطوات من الهاتف.

## طريقة إخراج APK من الهاتف
1. أنشئ مستودع GitHub جديد، مثلاً: `DukhanOff`.
2. ارفع **محتويات هذا المجلد** إلى المستودع، وليس ملف ZIP داخله.
3. بعد الرفع، افتح تبويب **Actions**.
4. اختر workflow باسم **Build DukhanOff APK**.
5. اضغط **Run workflow**.
6. بعد انتهاء البناء، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
7. نزّل `DukhanOff-debug-apk` وفك الضغط عنه، وستجد `app-debug.apk`.
8. ثبّت APK على هاتفك.

## ملاحظة
هذا إصدار Debug للتجربة. قبل نشره على Google Play نحتاج تجهيز نسخة Release موقعة ومراجعة سياسات المتجر.
